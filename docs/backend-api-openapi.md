# 后台开放接口文档说明

## 文档入口

开发环境使用 FastAPI 自动生成文档：

- Swagger UI：`/docs`
- ReDoc：`/redoc`
- OpenAPI JSON：`/openapi.json`

## 生产环境要求

生产环境不应无条件公开调试文档。建议采用以下方式之一：

1. 仅在内网或 VPN 开放。
2. 为文档入口增加管理员认证。
3. 发布脱敏后的静态接口文档，不暴露密钥、内部地址和调试接口。

## 后台接口分组

| 分组 | 主要内容 | 权限 |
| --- | --- | --- |
| 候选人管理 | 简历、初筛、投递关系 | HR / 超级管理员 |
| JD 管理 | 创建、发布、暂停、关闭职位 | HR / 超级管理员 |
| 面试流程 | 面试计划、时间协调、流程状态 | HR / 面试官 |
| 面试记录 | 对话、报告、评价 | 面试官 / HR |
| Offer 管理 | 发放、接受、拒绝 | HR / 超级管理员 |
| 系统管理 | 用户、角色、审计日志 | 超级管理员 |

## 接口文档最低要求

每个接口必须说明：

- HTTP 方法和完整路径
- 身份认证和角色要求
- 请求参数及校验规则
- 成功响应示例
- 失败响应和错误码
- 幂等性与并发限制
- 是否产生通知或审计日志

高风险接口（删除、恢复、导出、状态变更）必须在文档中明确前置条件和不可逆影响。
